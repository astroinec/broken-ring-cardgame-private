# 《断环》路线图

> 当前阶段：P0 定方向（2026-10-26 重写）
>
> 目标：一款完整三幕、可以放进作品集的卡牌肉鸽成品。
>
> 旧路线图（M0～M4，v0.5～v0.9）的记录保留在 git 历史里。

---

## 一、这次为什么重写

旧路线图把美术、动画、音效全放在最后，验收只看自动测试和机器人模拟。结果是规则很扎实，但打开游戏只有文字按钮，从来没有真人玩过，一点都不像游戏。

新路线图改三件事：

1. **画面、手感和规则一起做。** 每个阶段都要有能看、能玩的东西。
2. **真人说了算。** 每个阶段的门槛里都有真人试玩，自动测试只用来防止改坏。
3. **用户确认才算完。** 每个阶段交付时附截图或录屏。

## 二、已定的方向

- 用途：个人作品集、内部展示。
- 范围：完整三幕，加一个终章。
- 画风：米格诺拉大黑块加新川洋司泼墨，详见 `design/ART_BIBLE.md`。
- 世界观、术语和文案规矩：详见 `design/INTEGRATED_DESIGN.md`。
- 战斗：支持一到三个敌人。
- 角色：4 个（缝线人、哑书记、背棺人、钟表童），以后还能加；每人 3 个流派。详见设计文档第七节。
- 素材：可以用 AI 生成、模仿已有画风，但要统一风格，不做随手的低质量素材。

## 三、保留什么

现有代码里这些继续用，不推倒：

- 规则层和界面层分开的结构
- 伤害、格挡的修正顺序
- 固定种子可复现
- 存档和读档
- 自动测试和数值模拟的框架
- 删名者"涂黑你的牌、你能恢复"的核心玩法

要改的：术语全部换成新词；战斗改成多敌人；界面整个重做；文案全部按新规矩重写；内容按三幕重新铺。

## 四、阶段

### P0 定方向（进行中）

- [x] 审查旧项目
- [x] 选定画风，出检验图（角色、卡面、死亡画面、标题画面）
- [x] 写一体化设计：世界观、术语、真相表、文案规矩和样本、三幕敌人
- [x] 写美术规范
- [x] 重写路线图
- [ ] 用户确认以上文档
- [ ] 写三幕的完整线索清单：每条线索落到哪张牌、哪个怪、哪个事件
- [ ] 定第一幕的完整内容表：牌、怪、遗物、事件的具体数值和文案

**门槛**：用户确认画风、术语、文案样本和第一幕内容表。

### P1 第一场战斗做到成品质量

只做第一幕开头的 3 场普通战斗和 1 场精英，但要做到能直接放进作品集的程度。

- 规则：多敌人和选目标；术语换新；初始牌组 10 张；普通战斗打 4～6 回合；角色做成数据表，加角色不改战斗代码
- 卡牌：索引卡样式；悬停放大；拖拽出牌；关键词悬停说明
- 怪：立绘；意图图标加数字；血条和格挡；受击、死亡化墨
- 主角：立绘；过载越高墨点越多
- 声音：出牌、命中、格挡、过载爆的音效，一首战斗音乐
- 资源：在 `assets/ASSET_LIST.md` 登记

**门槛**：

- 至少 3 个真人试玩。不看说明，5 分钟内说得清怎么玩
- 录一段完整战斗的视频，用户确认手感和画面
- 原有测试改完后全部通过

### P2 第一幕完整

- 第一幕全部内容：普通怪 4～5 种、精英 2 种、删名者 Boss
- 缝线人三个流派做齐：35～40 张牌，每个流派至少 1 件遗物
- 可视化地图：档案目录样式，连线、图标、悬停预览
- 商店、休息点、事件的界面
- 叫醒、死亡、过幕的画面
- 第一幕的全部线索投放到位

**门槛**：真人从头打到第一幕 Boss，记录用时、死因、哪里看不懂；用户确认。

### P3 第二幕、第三幕

- 每幕：普通怪 4～5 种、精英 2 种、Boss 1 个、事件 4～6 个、新牌 10～15 张、遗物 5～6 件
- 第二幕机制：寄生、复活、往你牌组塞东西
- 第三幕机制：定住、重放、记住你的出牌顺序
- 三幕的线索互相呼应
- 加入哑书记和背棺人，各自三个流派，连同解锁事件

**门槛**：每幕做完都有一次真人试玩加用户确认。

### P4 终章和多局

- 终章（档案馆）
- 加入钟表童，三个流派，连同解锁事件
- 结局（每个只给一个章、一句话）
- 页边字、弥拉台词随局数变化
- 图鉴：杀得多了解开，有几行永远不解开
- 解锁新牌只增加选择，不加永久数值

**门槛**：至少一个真人连续玩 3 局以上，说说他拼出了什么、还有什么想不通。想不通的不一定要修（见设计文档第二节第 6 条）。

### P5 打磨和导出

- 设置：音量、分辨率、动画速度
- 卡牌图鉴、怪物图鉴
- macOS / Windows 导出
- 两轮外部试玩，只修有证据的问题

**门槛**：拿到一台没装过的电脑，双击就能从标题玩到结局。

## 五、做事的规矩

- 每个阶段先出小样，用户确认了再大批量做。
- 文案写完先对照 `INTEGRATED_DESIGN.md` 第二节自查，尤其是"说人话"和"不写结论"。
- 自动测试和模拟只用来防止改坏、找极端情况；数值最后按真人试玩调。
- 不再说"测试全过就算完成"。
